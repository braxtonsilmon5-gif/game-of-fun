# Hero Clash Arena

A browser fighting mini-game inspired by arcade 1v1 fighters, featuring MHA-themed characters.

## Run locally

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.

## Controls

- **Deku**: `A`/`D` move, `W` jump, `F` quick punch, `G` heavy smash
- **Bakugo**: `J`/`L` move, `I` jump, `;` quick blast, `'` AP heavy shot

First to deplete the opponent health (or have more health when the timer ends) wins.
